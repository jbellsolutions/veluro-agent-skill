# Evidence and publication notes

The September 8, 2026 operating baseline contains 42 feature runbooks, 95 captured screen states, 53 opened help guides, 662 normalized source-observed API call templates, 28 paths in an inferred OpenAPI subset, 66 model entries and 43 service presets.

## What this site contains

The full operating manual, agent instructions, all feature runbooks and their observed UI controls, API guide and discovered call catalog, model/service catalogs, verified schemas, maintenance procedure, verification register and demo findings. The [downloadable documentation package](downloads/veluro-documentation.zip) includes these materials and this searchable reader. Agents can begin with [llms.txt](llms.txt) and use [llms-full.txt](llms-full.txt) for the combined Markdown reference.

## Private evidence archive

The original complete 98-file portable package and the six consolidated project-source documents are stored privately in the owner's here.now Drive. They include the complete meeting transcript, raw account-specific UI/API observations, draft tests, source attribution and reader screenshots. The raw evidence files are not public website assets. Source filenames and offsets in the published references remain historical citations to that private archive.

The website replaces account-specific record identifiers with placeholders. Credentials and session tokens are excluded from both editions. Model slugs, UI field names, documented procedures and evidence labels are retained.

## Verification boundary

Direct preflight/catalog reads comprised 26 checks, of which 25 returned 200 and one unsupported GET returned 405. Two controlled local draft lifecycles were completed and cleaned up. A name-only campaign update preserved structured copy; replaying the full creation body changed its representation.

Read [the verification register](VERIFICATION.md) before operating. Live ads, outbound delivery, publishing, generated media, provider connections, production optimization and multi-client isolation have not been certified by this baseline. A source-observed API entry is not a vendor-supported API contract.

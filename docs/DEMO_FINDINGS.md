## Statements that should not become unqualified promises

The demo's campaign speed claims depend on input quality, provider availability, account connections and review. AI output must still be checked. Simulations are forecasts. An intent list does not establish every buyer in an area. A free trial claim does not establish which exact features a newly created consumer account can use. An “unlimited” advanced search statement does not remove the separately observed limits on intent, media, coaching or active campaigns.

## Changes and discrepancies since the demonstration

The live outreach setup includes Gmail/Outlook/SMTP mailbox instructions and a mailbox API, while the call discussed adding alternate SMTP. The current Meta integration banner discloses approval gating. LinkedIn Compose explicitly says it never sends on the user's behalf. The help still contains older sidebar names and audience-creation labels. The operating instructions therefore prioritize the inspected live UI and attach confidence labels to the demo's remaining claims.

The founder offered follow-up materials and support in the call. This milestone did not email, message or request those materials from anyone. If supplied later, add them as dated evidence and re-check any claims they change.
